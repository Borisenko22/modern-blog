# Modern Blog 🇺🇦

Сучасний блог, побудований з використанням React, TypeScript та Bootstrap.

## 🚀 Технології

- **React 18** - бібліотека для користувацьких інтерфейсів
- **TypeScript** - типобезпечна розробка  
- **Bootstrap 5** - CSS фреймворк
- **React Router** - навігація
- **Vite** - швидка збірка проекту

## 📦 Встановлення

```bash
# Клонувати репозиторій
git clone https://github.com/YOUR_USERNAME/modern-blog.git

# Перейти в папку проекту
cd modern-blog

# Встановити залежності
npm install

# Запустити проект
npm run dev
